# Documentos · Castilla y León · marzo de 2026

Esta carpeta conserva el contrato electoral de Se Acabó La Fiesta para las autonómicas del **15 de marzo de 2026**. La fecha aparece en la conclusión, página física PDF 22. El documento tiene 22 páginas y se conserva sin alterar, con procedencia, consulta, tamaño y SHA-256 en el JSON contiguo.

El original se obtuvo de la ruta pública HTTP del propio servidor del partido; la descarga HTTPS directa falló. No se ha generado un PDF nuevo ni se ha tomado una copia de terceros. El manifiesto de consulta `Elecciones/Generales Noviembre 2026/programas.json` permite encontrarlo desde la ficha de SALF, pero su ubicación, título y tipo `territorial` mantienen su elección real.

El inventario editorial se integra en `Cuestionario/analisis.json`. Las preguntas conservan `territorialScope`, con el ámbito y la fecha de este documento. No constituyen un programa nacional de SALF, ni compromisos acreditados del 29N, ni evidencia para sus ejes nacionales. La búsqueda en la web oficial y documentos públicos del 18 de octubre de 2026 no localizó un programa nacional; ello no prueba que no exista.
