# Castilla y León

Consulta del 15 de octubre de 2026. Gobierno y Cortes comparten la presentación regional: biblioteca horizontal arrastrable, cronología, organigrama y hemiciclo fijo, sin zoom, con filtros y fichas enlazadas.

- Doce legislaturas desde 1983 y 1.114 fichas de legislatura consultadas. El registro histórico conserva sucesivas adscripciones y bajas: no representa a todas esas personas simultáneamente. Las últimas adscripciones sin «Hasta» forman la composición archivada y se contrastan con la capacidad que publica la Cámara para cada legislatura. La XII conserva los 82 titulares del Pleno vigente en la consulta.
- El marco histórico publicado por las Cortes se conserva como marco documental; su final no se presenta como fecha individual de cese ni como disolución del Pleno. Las Mesas antiguas disponibles se mantienen aparte sin intervalos diarios no acreditados. Algunos directorios de órganos ignoran el parámetro de legislatura y devuelven la Mesa actual: esa respuesta no se reutiliza como histórico.
- Quince nombramientos presidenciales, incluidos los relevos entre elecciones, contrastados con el [dosier del Senado](https://www.senado.es/web/conocersenado/biblioteca/dossieresareastematicas/detalle/index.html?id=presidentes_gobiernos_17) y el BOE. Distinguir fecha del real decreto y toma de posesión.
- El [catálogo institucional de altos cargos](https://analisis.datosabiertos.jcyl.es/explore/dataset/altos-cargos/) documenta el Gobierno de 2026. Se reúnen las competencias de cada persona, conservando doce titulares únicos, incluido el presidente y las dos vicepresidencias. Las URLs internas del gestor de contenidos se resuelven contra el portal público `gobierno.jcyl.es`, conservando el mismo identificador y recurso. Los cuadros históricos identifican sus fuentes primarias y complementos enciclopédicos; no se afirma que exista una reconstrucción diaria completa.

El servidor público de las Cortes permite consultar algunos archivos por HTTP aunque su acceso HTTPS falle. Se conserva la procedencia y no se desactiva la validación de certificados. Las fichas individuales que el portal devuelve con error permanecen identificadas en la auditoría, con el registro nominal conservado. No se incorporan contactos, declaraciones patrimoniales ni fotografías genéricas. Las fotografías originales, estudios publicados y trayectorias pertenecen a la carpeta personal; grupo parlamentario no equivale a militancia.
